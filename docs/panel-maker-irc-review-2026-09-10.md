Every family-specific thing was swapped: IRC client chrome, IBM Plex Mono faces, five terminal themes, 13 pixel icons in the theme palette, IRC copy and gags. Each build was captured with Playwright (desktop + mobile UI, all presets at 2x and at 320px on #18181b, a 21-character nick with an uploaded avatar, Phosphor and mIRC Light variants, a measured contrast report) and handed to a fresh independent reviewer (graphic designer + ~150-viewer streamer who buys panel packs; no memory of the build). ## What's in v2

- 10 presets in the zip (About, Schedule, Rules, Socials, Discord, Subscribe, Support, Commands, Specs, Custom) plus two optional slots (`#youtube`, `#business`) that are off by default — Twitch gives one link per image, so YouTube / merch / business want their own panel.
- IRC client chrome from the widget's own tokens: 1px accent frame, `#channel — server` title bar with a 16px pixel icon, a three-row log, a `● CONNECTED  label: value █` status bar. `[hh:mm]` timestamps count up from the buyer's go-live time (never stale) and are dropped per panel only when a line would not fit — the preview status line says so.
- Layouts: whois card with a framed avatar well (`<nick>` in the streamer red); a `[MON] [TUE]` mode line with live days lit; one row per social platform (`[YT] YouTube @handle`, platform-name column dropped before any handle is truncated); `*** nick invites you to #discord` with a `/join` prompt; `DCC SEND thank_you.wav` gag or an opt-in numeric goal with a segmented bar; numbered / `+voice` / `*` lists with "key - detail" colouring; an adaptive nick list (you as `@op` + two mods / regulars from section 2, capped at 14 cells) that fills the right side of list panels whenever the lines leave room, per-panel toggle.
- **Prompt-line call to action** on link panels: `> /follow█`, `/join #discord`, `/subscribe`, `/tip` with an optional note, editable per panel; lists show two lines + the prompt, or three lines without it.
- True bitmap text from a 1-bit IBM Plex Mono atlas (Bold 16 titles, Bold 14 nicks/keys, Medium 14 body, Medium 13 dim; SIL OFL via `@fontsource/ibm-plex-mono`, pre-rendered through FreeType by `make_atlas.py`). All three 13/14px faces share an 8px cell, so stamps, nicks and body sit on one column grid; the first glyph of every row is bearing-compensated so every panel shares one ink edge.
- Five themes (IRC Dark = the widget, Phosphor, Amber, mIRC Light, Solarized) + Background / Frame / Channel pickers. Every text colour is guarded: ≥7:1 body and dim, ≥6:1 title, ≥5:1 accent / green / role colours, dim-on-bar ≥7:1. Mono themes collapse nick and brand colours to the phosphor.
- Nick (25), server name, go-live time, timestamps toggle, avatar upload (pixelated or smooth), nick-list names, per-panel title / icon (13 pixel icons) / lines / prompt / status / "Image Links To"; per-panel reset; browser persistence; Preview set; download one PNG or the set numbered in upload order + README (upload steps, per-file Image-Links-To and suggested description). Export buttons in the preview window and again at the end of the controls. No libraries, works offline (no web fonts at all).

## Still open (ranked, from the last two reviewers)

1. **A tall layout** (640×400, 7–9 body lines) for Rules / Commands / Specs — the house spec is 640×200 and the retro maker has the same limit, so this is a catalogue decision, not a one-maker fix. Both recent reviewers called the 3-line body the single thing holding the product under 8.5.
2. **The 13px dim layer** (timestamps, status bar, server name) is 1px-stem text at 320px. Options: a 30px status bar with the Medium 14 face, or accept it as terminal texture. Timestamps could also default off on list panels to buy back 8 cells.
3. **Support panel semantics** — reviewers split three ways on the DCC gag (100%/done, ~66%/sending, chrome-coloured). Shipped: chrome-coloured full bar + green `/tip` prompt. The last reviewer would make the gag opt-in and lead with `/tip`.
4. **Fake defaults**: `ModMike, VIPVictor` in the nick list and `3 ops online` on Discord ship unless the buyer edits them. Empty-by-default would leave the nick list with one name (and bring back the empty right half).
5. Smaller: quantise the uploaded avatar to the theme palette on mono themes; the `share` icon is the weakest at 16px; list rows carry no `<nick>` / `***` (authenticity stuck at 8); `[ help ]` scrolls to a two-line hint rather than a help block; a `_` cursor option to match the widget's status bar exactly.
